# 混沌爬塔

首页独立入口“混沌爬塔”，仅支持单人。沿用原有组别、地图、难度、敌人、物品和锻造流程。玩家天然技能替换为本局固定的随机技能牌；之后获得的角色和技能锻造卡也采用本局牌池。

## 生成规则

借鉴 AutoAnthony 的结构化组件方式，先把 tswn 技能拆成操作、目标与数值，再组装为两至三项顺序操作。普通技能与 covid、lazy、saitama 专用机制均有组件来源。召唤采用混沌子体规则，原生 Boss 感染使用引擎入口；卡面明确说明实际效果，不声称保留原 Boss 的全部身份机制。

名称直接拼接实际来源技能的原字片段，不加前缀、分隔符或编号。例如“投毒”的“投”与“火球术”的“火球”组成“投火球”；“魅惑”与“生命之轮”的“之轮”组成“魅惑之轮”。名称不决定技能行为。图标从现有技能图标随机选取，与效果独立。

本局牌池与角色技能归属写入存档；读档不重抽。熟练度仍使用原有有效上限和锻造概率，数值从同一个结构化程序生成简短描述。一次出牌扣一次 MP，操作按顺序执行，每项按自己的目标重新选取，无目标时跳过该项。

## 卡牌库

物品栏新增“卡牌库”，按角色列出技能、熟练度和简短描述。战斗外可将卡牌拖到其他角色：源角色失去此技能，目标保留同等熟练度；已有同名卡时保留较高熟练度，不额外叠加。拖入删除区永久移除。刷新、武器装卸或属性重算都不会恢复已移出或删除的卡。

战斗中禁止调整归属。混沌手牌采用加长卡面，在基础信息下完整展示操作描述。原技能不作为隐藏的被动继续发动，普通攻击仍可用。

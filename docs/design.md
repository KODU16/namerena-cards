# 玩法设计（v0.2）

## 一句话

随机名字开一个角色，沿天梯 1A 从最底下往上打 8 场。战斗**由 tswn 引擎执行**，
行动顺序、伤害、状态、召唤全部是引擎原样结果；玩家只决定「轮到自己的单位时出哪张卡」。

## 一局流程

```text
首页
 └─ 新局：选战队名 → 随机名字（可重抽 2 次）
     └─ 第 1..8 战：选出战角色 + 最多 2 张战术卡 → 开战
          ├─ 胜：二选一（随机技能卡 / 随机角色卡）
          │    ├─ 技能卡 → 进「技能卡」栏，可在锻造里加给角色（加完消耗）
          │    └─ 角色卡 → 直接进卡组，下一场可选
          └─ 负：本局结束
```

## 战斗：引擎驱动

- 输入是两行 `名字@阵营+ol:{...}` + `seed:`，直接喂给打过补丁的 `tswn_wasm`。
- **行动顺序**：tswn 的行动条（速度 + RC4 步进），不是双方轮流。
- **玩家可操作单位**：本体 + 分身（clone）。幻影 / 丧尸 / 使魔由引擎自动行动，不抽卡。
- **一次行动 = 一张卡**：轮到某个玩家单位时抽 3 张主动技能卡 + 普通攻击，选 1 张；
  选择写进强制队列，引擎按 tswn 的方式结算。
- 能量只决定「这张卡能不能打」：`2 + floor(帧序/5)`，上限 4；费用按熟练度
  `≥45 → 3 / ≥15 → 2 / 其它 1`。不够的卡变灰。
- **净化（skldisperse）是敌人专属**：玩家抽牌池里直接剔除，不会出现。

## 被动与触发

- 反击 / 伤害反弹 / 护身符 / 蓄盾 / 吞噬 / 亡灵 / 垂死 / 隐匿等由引擎的 hook 自动触发，
  不占手牌、不能主动出招（强制队列对 25..34 返回 None 时回落）。
- 蓄盾在 tswn 里是行动前累积，不是主动技，这点由引擎保证。

## 奖励与锻造

- 每胜一场二选一：
  - **技能卡**：随机技能 + 随机熟练度（10~79），排除净化；
  - **角色卡**：从卡池里随机一个未拥有的角色。
- 技能卡只能在「技能卡」栏里点选后，再点角色完成锻造：
  - 角色已有该技能 → **熟练度叠加**；
  - 没有 → 新增该技能；
  - 锻造后消耗这张技能卡。

## 与 tswn 的关系

| 项目 | 来源 |
| --- | --- |
| 八围、技能、熟练度、头像 | `to_diy` / `name_to_png_base64`（官方构建结果） |
| 行动顺序、伤害、状态、召唤、随机数 | 打补丁后的 Runtime（`battle_replay_forced`） |
| 手牌、能量、费用、奖励、锻造 | 本作的卡牌层 |

前端不再自己算伤害：`js/combat.js` 已停用，战斗走 `js/duel.js`。
引擎补丁说明见 [engine-interface.md](engine-interface.md)。

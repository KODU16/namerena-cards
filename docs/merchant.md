# 武器商人与商店品质

武器商人每层独立以 33% 概率出现。首次进入生成三把不同名字的武器，库存与售出状态保存在地图节点中；购买、切换页签或读档不会重新生成库存。

## 交易价格

使用固定基准角色的 tswn 自然构建，比较装备前后的八围和技能，避免保底倍率、角色锻造及队伍切换影响回收报价。

- 属性净加成折算：七围每点计 3，体力每点计 1。
- 总估值：`400 + 属性净加成折算 × 6 + 技能熟练度净增 × 10`，限定在 400～3000 分。
- 买入价：估值的 160%，向上取整到 50 分。
- 出售价：估值的 50%，向下取整到 25 分，最高 1500 分。
- 重铸费：`1800 + (层数 - 1) × 50 + 已重铸次数 × 450` 分。

重铸随机生成一个不同的武器名，不保证变强。单次费用高于最高回收价，买入价也高于出售所得，避免循环交易刷分。重铸次数随物品身份保存，装备、卸下和读档均不重置。已装备的武器需要先卸下，角色属性及技能同步恢复后再交易。

## 商店品质与净化

普通商品默认蓝色品质；每个商店以 8% 概率额外出售一张金色净化锻造卡。熟练度为 1 或 2，价格由第一层 4500 分逐步升至第十层 6750 分。

所有商店库存按节点保存，每件商品只能买一次。净化卡通过正常锻造流程消耗并判定成功率，成功后该角色可抽到净化；换装和读档保留来源。净化手牌使用独立金色样式，MP 不足时保留金色品质标识。

## 图标

宝箱关闭、宝箱开启、武器商人均为 32×32 RGBA 像素图，使用现有图集调色板，四周至少保留 2 像素透明边缘。运行 `python tools/build-merchant-icons.py` 重绘，再运行 `npm run build:icons` 更新共享图集。

## 诅咒商人

每层独立以 33% 概率出现，使用现有诅咒像素图标。商人立绘位于窗口左侧，图片按需加载并生成内容指纹。普通商店的技能卡、角色卡、武器、药水、战术卡均可出现在交换库存中；同一人物的库存首次打开后固定并保存，已交换商品不会重复领取。

属性交易扣除全体已有角色的本体基础值：本体天然构建加永久锻造，再减已累计诅咒，不计武器和开局加成。排除智慧。令所有角色可承受代价的最小值为 `m`，随机整数 `n` 满足 `1 <= n < m`，单次最多 40；没有合法正整数时不生成此项代价。HP 按三倍计算：生成范围先除以 3，显示并扣除 `3n`，物品强度仍按 `n` 计算。成交时再次检查所有角色，不满足则整笔拒绝。

技能交易按卸下武器后的本体技能组选择最高熟练度，包含技能卡和篝火锻造。成交后移除本体技能和全部锻造记录，将本体贡献永久归零；保持原武器装备，武器重建中超过本体天然熟练度的贡献继续生效。卸下、换装、战术、读档不恢复已移除的本体贡献，也不能再次锻造恢复。代价中的“降低 n”和失去的技能名称显示为红字。

以属性代价 20 或失去技能熟练度 40 为标准强度。技能卡熟练度、药水数量和战术倍率随代价增长；新角色以永久锻造记录附加属性；武器按代价目标估值从随机候选中选择。HP 三倍仅影响代价，不额外提高物品强度。金色净化仍为熟练度 1～2。

战术卡的商店、奖励、物品栏与备战描述统一显示缩放并取整后的实际加成，例如基础“守护 +30 级”、倍率 1.3 时只显示“守护 +39 级”。倍率仍在内部用于同名强度比较，卡面不再额外显示。

## 精英与 MP 显示

第一层只生成全属性 ×1.2 的精英，第二层为 ×1.5；第三层起分别抽取全属性 ×2 或双倍人数。备战和战斗八项属性均标蓝色倍率；旧存档已有精英在备战时沿用原名字调整为新曲线。

玩家点击手牌立刻显示扣除已确定的 MP 消耗。回放中的行动尾部回复等所有行动段落播放完成后才显示，MP 槽右侧蓝字显示实际回复量。引擎仍只结算一次真实消耗。

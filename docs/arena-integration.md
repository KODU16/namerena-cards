# 多人模式接入边界

cards 提供多人模式的浏览器界面、静态规则数据和客户端 WASM；它们会随本仓库 `main` 的静态发布自动更新。

生产多人接口属于 `namerena-platform`。cards 无权启动、更新或说明生产服务端；接口不可用时，前端应保持可理解的提示，而不是尝试由静态文件接管。

如需扩展多人接口、存储、结算或房间逻辑，请在 `namerena-platform` 的私有分支或 PR 中提交并由平台维护者审查和发布。本仓库不记录服务器结构、连接信息或运维步骤。

供平台维护 Agent 执行的安全接入门槛见 [大逃杀接入说明](arena-platform-agent-handover.md)。

# 技能说明与战斗立绘

普通技能说明以 https://deepmess.com/zh/namerena/skill.html 为表述基准，将伤害、目标、附加效果和触发条件整合为一段，统一维护在 js/skills.js。净化采用指定说明：必定命中、100%魔法攻击、对方 MP−64、去除有益效果、对召唤兽双倍伤害。自爆、附体、隐匿等参考页未完整列出的技能结合 tswn 实现补充。

说明是展示口径更新，不改变引擎战斗算法。参考页与现有 tswn 部分数值实现存在差异，例如伤害的随机强度算法和净化低 MP 时的分段扣费；本次按指定参考页统一说明，没有顺带改动战斗规则。混沌技能仍由实际操作配方生成描述，不套用原技能完整描述。

## 立绘与卡面

素材来自用户提供的本地“卡面立绘”目录。26张原稿生成640像素 WebP 衍生图，以ASCII文件名存储在 assets/card-art；不修改原稿。全部25项主动技能及狂暴攻击使用对应立绘，普通攻击画框留空。无独立原稿的被动技能采用 js/card-art.js 中的明确别名，混沌牌按其随机技能图标选取对应立绘。

静止手牌宽高比固定为0.618，顺序为左上MP圆标、居中加粗名称、立绘、技能描述。描述从同一技能元数据取得，数字、百分比和负值以蓝色加粗显示。描述正文完整排版，不使用卡内滚动；空间不足时先缩小立绘和战场留白，保证文字留在视口内。手机使用单行横向浏览手牌，不让第二排文字落到屏幕外。

发布构建将立绘转为内容指纹路径，卡图按需下载。修改素材或描述后执行 npm run build:site，确保浏览器不会继续使用旧文件。

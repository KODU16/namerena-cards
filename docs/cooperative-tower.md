# 合作爬塔

首页选择“联机 · 合作爬塔”，创建或加入六位房间号。支持 2～4 人，组别为 1A、1B、2A、2B，每人携带对应的 1 或 2 个名字。房主可选择标准至 A20 难度、每层节点数，以及 5～180 秒出牌时限。

## 路线与敌人

仍有操作权和库存角色的玩家全部投票到同一节点后进入；再次点击其他可达节点可换票。节点右侧显示投票者队徽和队名。库存耗尽者和永久旁观者不参与投票。

敌人数按开局人数固定，后续有人旁观也不减少。试炼重新生成独立随机 @! 角色，每个角色独立决定是否携带武器。天梯节点复制原阵容，显示名字、头像与属性一致。A20 第十层将天梯第 1、第 2 名的阵容各复制开局人数倍，并通过真实 tswn 分组构建保留其组队加成。

## 战斗与旁观

每位玩家只操作自己的角色；所有玩家角色倒下才算全队战败。胜利时保留本场倒下的角色。全队战败后出战角色不可再用，有库存者换人，无库存者旁观。

“永久退出操作并旁观”不可撤销：角色交回 tswn 引擎原生选招，跳过功能节点，全败后自动按库存顺序补位。剩余成员继续投票，开局敌人数不变。

手牌超时由主站时钟执行。当前出牌角色左侧蓝色空心圆环显示剩余时间，刷新不会续期。左右角色列表分别支持滚轮滚动并保留各自滚动位置。

## 共享物品与个人节点

天梯分数全队共享，战斗分数掉落为原数值的开局人数倍。功能节点内容独立生成，每位仍在操作的玩家分别处理并完成后前进。

物品栏全队共用：武器、锻造卡、战术、药水、能力和遗物只有同一份权威状态，角色库仍按玩家保存。武器已占用时在角色卡选择框中淡灰禁用，标注“（正被装备者名字使用）”；共享物品栏同时显示占用者队徽与队名。消耗或占用由服务端事务校验，重复请求不能重复使用。

遗物获得后全队生效。多人的商店报价统一去重，已持有遗物不会再次出现在其他人的未购买报价中。

## 平台接入

浏览器复用大逃杀的同源请求、登录与 CSRF 恢复方式。合作接口位于 /api/cards/coop；房间、动作版本、占用与结算由 namerena-platform 保存，战斗使用该仓库审核后的固定 Node/WASM 包。

Cards 静态发布不会自动启用这些新服务端接口。平台配套 PR 审核、数据库更新、后台时钟与功能开关启用后才能联机；启用前界面会明确提示服务尚未接通。

本地验证：node tools/verify-coop.mjs；发布构建：npm run build:site。

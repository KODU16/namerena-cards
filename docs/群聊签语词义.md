# 群聊签语词义与抽签词库

本次分析基于导出的 namerena 群记录，共 58,854 条消息；导出文件注明另有 99 条因损坏页未能读取。图片、语音占位、指令和榜单不能直接当作价值判断。下表统计包含该词的消息条数，并非纯人工发言次数或独立评价次数。

## 判断原则

- 猴、猴儿、猴区偏负面；本签池忽略猴区的专名义。猴完了是极负面的结果，不是完成任务。
- 豹、猎豹、小豹、大豹、神豹偏正面；豹完了通常是程度补语，表示太豹了，不能与猴完了按同一个后缀反向判读。
- 花瓶指纸面与实战落差，不因评分好看就判正面。滚木指异常或反复出错，不按木材等字面意义理解。
- 拜谢一般是认可，咦一般是反向评价；语料也有审核投票和普通疑问，统计不能全部视为情绪。
- 卖牢偏向抱怨、自嘲；波动、加成、断档需要修饰语，单独不能都判吉凶。不太豹、差点出货等按完整短语判轻负面，而不是看到豹或出货就判正面。
- 幻术、分身、苏生、净化、铁壁、护盾、命轮、聚气、蓄力、地裂、血祭、潜行、背刺、回避，以及轮椅等机制或组合名均有出现并经上下文检查；它们本身不能明确回答问题，因此没有作为独立签语凑数。
- 抬走存在施受双方，签池采用被抬走了的负面搭配；虚空有多种名词、名字用法，未作独立签语。无敌、强强等在原聊天中也可能反讽；短签只采用清晰的肯定义。

## 签池

签池为群语风格改写，并非 2000 条聊天原文。200 个核心短语各有 10 个简短口语变体，合计 2000 条不同文本；只用熟悉的判断词和普通程度、语气词，不创造新的专名或附加解释。每条包含语料中至少 5 条消息出现的核心词；猴完了出现 3 条，作为关键群语单独保留。

负面与正面各 1000 条，按强度顺序分为 40 档、每档 50 条；内部强度坐标从 −99.95 到 +99.95 等距排列，近中间表示轻微偏坏或偏好，不使用无法作答的中性名词。坐标只用于维护和均衡检查，不在抽签结果中显示。措辞强度是语义分档，不代表可测量的现实概率。

抽取在现成词库中逐条等概率进行，每条概率 1/2000；不根据问题内容、战斗、角色或账号调整。原始聊天、成员信息和账号数据均不进入网站或 Git 仓库。网页仅按需加载固定签池，结果仅显示短签。

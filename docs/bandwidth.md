# 流量与压缩发布

运行以下命令生成独立的压缩发布目录：

```powershell
npm ci
npm run build:site
```

发布时使用 `dist/` 的内容。直接部署仓库根目录仍然加载开发源码，不会使用这些压缩产物。

## 发布构建

- JavaScript 合并、裁剪未使用代码并压缩；引擎加载器独立压缩。
- CSS 和 JSON 压缩，HTML 去除注释及标签间空白；不生成 source map。
- WASM 预先 gzip 为普通二进制资源，浏览器使用原生 `DecompressionStream` 解压，再交给 WebAssembly 初始化；无需下载解压库，也不依赖 Pages 对 WASM 启用 gzip。
- 不支持原生解压的浏览器只请求原始 WASM。两种引擎文件虽然都随站点发布，但一次启动只请求其中一种。
- 应用、CSS、引擎加载器、WASM 和雪碧图按内容指纹命名；内容不变时 URL 不变，允许复用浏览器正常缓存。此机制不改变 Pages 的缓存期限，也不保证长期免下载。
- 只复制运行所需资源。天梯快照保留为按需下载，卡池仍由浏览器计算。
- 地图坐标、避让和夹角检查全部在本地计算，不产生额外网络请求。

## 兼容性验证

压缩引擎解压后与原始 WASM 字节一致，已验证原生解压加载流程能够初始化引擎。开发模式保留原始加载路径，便于本地修改和调试。
